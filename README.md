## The entry

One line of wedding vows for a robot couple, at most 160 characters. Ten
fresh candidates are scored against the judge's criteria in order —
on-subject, laugh in the line itself, vow voice with a promise, machine-side
detail, reads well aloud — and the winner is written to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

The chosen line is written to `/output/entry.txt` (single line, 1–160 chars).
